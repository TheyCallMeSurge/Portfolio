Overview

As part of the Syracuse University Rocketry Club (Orbit), I supported the Zephyr rocket program through avionics and propulsion testing.

My main focus was designing and building a thermocouple-based instrumentation system to monitor engine temperatures during static-fire tests.

What I Did

  • Selected K-type thermocouples and the supporting hardware for engine temperature measurement.
  • Wired the system and set up signal conditioning for reliable readings during a firing.
  • Wrote the embedded code and set up data acquisition for the test stand.
  • Worked with the propulsion, structures and software teams to integrate avionics hardware into the vehicle.

Results

  • Delivered a working thermocouple system used to record engine temperatures during Zephyr static-fire tests.
  • Gained hands-on experience with embedded systems, telemetry and rocket propulsion testing.
